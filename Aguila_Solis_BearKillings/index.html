How the data was prepared

The notebook's workflow, with what each step found in this file. The dashboard uses the cleaned version.

  1. Load the CSV

    Read the supplied file into a dataframe and keep an untouched copy for comparison.

    166 rows, 14 columns

  2. Inspect

    Reviewed shape, types and distinct values. Age was stored as text, and the age column header had a leading space.

    6 numeric, 8 text columns

  3. Missing and blank values

    Trimmed whitespace and non-breaking spaces. The one missing gender became "Unknown" instead of a guess.

    1 value filled

  4. Duplicates

    Looked for exact duplicate rows only. Similar names or incidents are not merged without source checks.

    0 removed

  5. Fix data types

    Stripped column names, converted age to a number and parsed dates. Month and year were re-derived from the date. Ages that are not numbers ("10 months", "5 months", "<10" and two "?") stay missing.

    161 of 166 ages valid

  6. Outliers

    IQR rule on age: Q1 is 22, Q3 is 52, so the fences sit at -23 and 97. Real historical cases are flagged for review, never auto-deleted.

    0 outliers flagged

  7. Feature engineering

    Added incident month, year, decade and a Northern Hemisphere meteorological season, all from the date.

    4 new columns

  8. Encoding

    Built a separate model-ready table with one-hot gender, setting and bear type. Names, locations and descriptions are left out.

    166 rows, 20 columns

  9. Scaling

    Standardized age into age_scaled in the model-ready table only. The readable table keeps real years.

    161 ages scaled

  10. Save

    Wrote a readable cleaned file and a model-ready file.

    59,172 and 13,271 bytes

  11. Validate

    Reloaded the saved file and checked shape, duplicates, missing values and types. Only the 5 missing ages remain.

    166 rows, 19 columns match

  12. Visualize

    Built ten charts from the cleaned data. This page rebuilds them with filters.

    10 charts

Read this before drawing conclusions

Counts are not risk

The file lists recorded cases only. With no population or time-outdoors figures, the charts cannot show how likely an attack is or what causes one.

Unknown origin

The CSV has no verifiable publisher, source link or data dictionary. The flag columns (Hunter, Grizzly, Hikers, Only one killed) follow the file's own labels.

Uneven coverage

Older years have far fewer records than recent ones, which likely reflects what was documented rather than what happened.
